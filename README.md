## 📖 عن الإضافة

**وذكر - Wazakker** إضافة بسيطة وخفيفة صُممت لتكون **صدقة جارية**، تذكّرك بذكر الله عز وجل أثناء انشغالك بالعمل أو تصفح الإنترنت.

تظهر لك إشعارات هادئة تحمل أذكاراً متنوعة من تسبيح واستغفار وصلاة على النبي ﷺ، دون أن تعطّل عملك أو تثقل على جهازك.
